# Sedition Blockchain Currency

## Official Currency: SED (SedCoin)

The native currency of the Sedition blockchain is **SED**, short for **SedCoin**.

### Denomination
- 1 SED = 1,000,000,000,000,000,000 wei (10^18 wei)
- Smallest unit: 1 wei

### Mining Rewards
- Block reward: 2 SED per block
- Block time: 10 seconds
- Annual inflation: ~6,307,200 SED (at constant block time)

### Not Ethereum
**Important:** SED is NOT Ethereum (ETH). This is a completely separate blockchain with its own native currency. While the technology is similar to Ethereum, SED tokens:
- Only exist on the Sedition blockchain
- Have no connection to the Ethereum mainnet
- Cannot be exchanged for real ETH
- Have no real-world monetary value

### Test Transactions
When testing the Sedition blockchain, you're transacting in SED, not ETH. The RPC interface uses similar formatting to Ethereum for compatibility, but all balances and values are in SED.
